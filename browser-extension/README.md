# Capturador BriqueGO

Extensão local para Chrome e Edge. Ela lê somente a aba atual, depois de um clique, e abre o formulário do BriqueGO preenchido.

## Instalar no Chrome

1. Extraia o arquivo ZIP em uma pasta permanente.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Escolha a pasta extraída `briquego-capturador`.
6. Fixe a extensão na barra do navegador.

No Edge, use `edge://extensions` e o mesmo procedimento.

## Usar

Abra um anúncio no Facebook Marketplace, OLX ou Mercado Livre, clique na extensão e escolha **Capturar anúncio desta aba**. Confira o resumo e clique em **Abrir no BriqueGO**.
